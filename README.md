# E-commerce Core (Homework 14.1)

Реализация ядра интернет-магазина: классы `Product` и `Category` с автоматическим подсчётом категорий и товаров.

## Функционал
- Класс `Product` (название, описание, цена, количество).
- Класс `Category` (название, описание, список товаров).
- Автоматический подсчёт общего количества категорий и товаров.

## Запуск
`python main.py`

## Тесты
`pytest --cov`
